How it works

What each diagnostic measures, and where browser limitations apply.

Latency

The tool times browser requests to configured HTTPS endpoints and reports the average successful response time. This includes network transit plus server/browser overhead, so it is not identical to ICMP ping.

Jitter

Jitter estimates how much successive response times vary. Lower variation generally means a more stable connection for real-time workloads.

Request loss

The loss percentage is based on failed diagnostic HTTP requests. It is an application-layer approximation and must not be interpreted as raw packet loss.

Download and upload

Quick checks use small transfers. Full diagnostics use larger adaptive transfers so faster links have more time to reach representative throughput.

Security signals

The browser can confirm signals such as HTTPS transport, secure-context status and mixed-content exposure. It cannot audit your router, wireless encryption, DNS path or local network.
